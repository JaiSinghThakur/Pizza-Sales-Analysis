# 🍕 Pizza Sales Analysis

An interactive Pizza Sales Analysis project built using **Excel, Power Query, Power Pivot, DAX, and Power BI** to analyze sales performance, revenue, orders, products, categories, sizes, and sales trends.

---

## 📌 Project Overview

This project analyzes pizza sales data to understand overall business performance and identify the products, categories, sizes, and sales patterns contributing to revenue and order volume.

The analysis was performed using Excel for data preparation and analytical modeling, followed by Power BI for the final interactive dashboard.

---

## 🎯 Business Objectives

The project aims to answer key business questions such as:

- How much total revenue was generated?
- How many orders were placed?
- How many pizzas were sold?
- Which pizza category generates the most revenue?
- Which pizza size is most popular?
- Which individual pizzas generate the highest revenue?
- How do orders change over time?
- How do individual pizzas perform across categories and sizes?

## 🧹 Data Preparation

The dataset was prepared using **Excel Power Query**.

Key data preparation steps included:

- Correcting and promoting headers
- Standardizing pizza size values
- Cleaning and transforming categorical values
- Checking data types
- Preparing tables for analysis
- Creating relationships between related tables
- Building a structured data model using Power Pivot

---

## 🧮 Data Modeling & DAX

The project uses a relational data model connecting the main pizza sales tables.

DAX measures were created to calculate important business KPIs, including:

- Total Revenue
- Total Pizzas Sold
- Total Orders
- Average Order Value
- Average Pizzas per Order
- Revenue by Category
- Revenue by Pizza
- Sales by Size

---

## 📊 Power BI Dashboard

The final Power BI report contains multiple interactive pages.

- Sales by Pizza Size

### 🍕 Product Performance

Provides a detailed analysis of individual pizza products.

Key visuals include:

---

### 📖 Documentation Pages

Documentation pages explain the purpose and analytical scope of the dashboards and describe the purpose of each visualization.

---

### 💡 Key Business Insights

The analysis identified several important findings:

- **Classic** is the top-performing pizza category by both sales volume and revenue.
- **Large** is the most popular pizza size by sales volume.
- **Thai Chicken Pizza** generated the highest revenue among individual pizzas.

## 🔍 Detailed Insights

### Category Performance

The **Classic** category was the strongest-performing category.

- Pizzas Sold: **14,888**
- Revenue: **$220,053.10**

### Product Performance

**Thai Chicken Pizza** generated the highest revenue among individual pizzas:

- Revenue: **$43,434.25**

### Size Performance

**Large** pizzas had the highest sales volume among the available pizza sizes.
